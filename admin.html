Firebase está sin configurar

El panel necesita las credenciales de tu proyecto para funcionar.

1. Abre assets/js/firebase-config.js y reemplaza cada PENDIENTE… por los valores de tu proyecto (Firebase Console → ⚙️ Configuración del proyecto → Tus apps → Configuración del SDK).

2. Repite los mismos valores en firebase-messaging-sw.js (la raíz) para que funcionen las notificaciones push.

3. Despliega las reglas de seguridad: firebase deploy --only firestore:rules,firestore:indexes.

4. Crea tu usuario administrador en Authentication y añade su UID a la colección admins de Firestore.

Las instrucciones completas están en el README.md del proyecto.

Suscripción de este dispositivo

Activa las notificaciones push en este navegador y vincúlalas a un cliente. Así recibirás los avisos de vencimiento (10, 5, 3 y 1 día antes) aunque la página esté cerrada.

Comprobando soporte…

Cómo funcionan los avisos automáticos

La Cloud Function verificarVencimientos se ejecuta todos los días a las 8:00 a.m. (hora de Colombia). Revisa la fecha de vencimiento de cada cliente y envía una notificación push cuando faltan 10, 5, 3 y 1 día. También marca como inactivo a quien ya venció y actualiza el estado por vencer a 15 días o menos.

Además, podrás lanzar un recordatorio manual desde el botón de cada fila en la pestaña Clientes.

Requiere el plan Blaze de Firebase (pago por uso). Para un proyecto de este tamaño el costo es de centavos al mes.
